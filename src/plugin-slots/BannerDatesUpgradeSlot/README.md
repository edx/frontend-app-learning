# Banner Dates Upgrade Slot

### Slot ID: `org.openedx.frontend.learning.banner_dates_upgrade.v1`

### Slot ID Aliases
* `dates_upgrade_banner_slot`

### Description
A plugin slot for rendering upgrade notifications in the dates section of the course home banner. This slot is rendered in the course home dates tab and allows plugins to inject custom alerts and notifications related to course upgrades.

### Props:
* `courseId` - The course ID (string)

### Example Usage
Plugins can inject components here to show upgrade-related alerts and notifications in the dates banner section.
